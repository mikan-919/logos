# 外部境界における同期と Conflict

## 対象範囲

Logos コア内には Conflict は発生しない（単一ストアのため）。
本ドキュメントは **外部サービス（GitHub/Linear など）との境界のみ** を扱う。

## イベントフロー

```
外部サービス → Adapter（外部レイヤー） → Logos 単一書き込み口 → 変更通知 → System
```

## Event はペイロードを運ばない

Event は「変化の中身（diff）」ではなく **「このEntityを見直せ」という合図**。
System は Component の現在値を読み直して整合を取る（reconciliation）。
書き込みが発生しなければ次の Webhook も飛ばない（echo は no-op で消滅）。
外部が値を変換する場合（`"B"` → `"b"`）は**正規形での比較**が必要。

## 並行 Conflict の判定

Logos 側が Component ごとに「最後に書いた値 / 見た値」を保持する。

```
incoming == 最後に書いた値              → echo → no-op
incoming != 最後に見た値
   かつ 相手側にも未反映の変更あり     → 並行 = Conflict → ユーザーに確認
   かつ 相手側に未反映の変更なし       → 新しい編集 → 受け入れて同期
```

並行 Conflict は Merge 哲学と一貫して **ユーザーに委ねる**（情報を失わない）。

## まとめ

| 状況 | 対処 |
|------|------|
| echo | 収束モデルで自然消滅 |
| 非冪等な外部変換 | 正規形で比較 |
| 因果順序のある対立 | 下流が勝つ / no-op で自動解決 |
| 並行 Conflict | ユーザーに確認させる |
